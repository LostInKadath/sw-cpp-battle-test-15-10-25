# **Известные недостатки и сомнения по решению**
1. Симуляция однопоточная -- World не потокобезопасный. Нужны критические секции при работе с мапами.
2. Обработка ошибок входных данных неконсистентная. Где-то явно проверяется сущетвование юнита на карте перед действием, где-то я полагаюсь на исключение из at().
3. Ворон должен уменьшать дальность атаки стрелка на 1. Этот модификатор работает уже после того, как стрелок выбрал ворона своей целью. Поэтому ворон может "улететь" из диапазона.
4. Неконсистентно обрабатываются события MARSH_STARTED и MARCH_ENDED/UNIT_MOVED -- первое из Simulation, другие из World. Неясно, в какой именно момент начинается марш.
5. ...
